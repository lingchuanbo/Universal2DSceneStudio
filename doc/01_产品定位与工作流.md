# 01 产品定位与工作流
## 产品定位
VFXForge Studio 是独立于 After Effects 的 AI Native 程序化视觉特效创作软件，面向游戏特效、2D/2.5D 动效、动态图形和可复用特效资产生产。它不是单一粒子编辑器，而是将程序化几何、节点网络、动画、模拟、GPU 渲染、AI 助手和导出统一到同一工程。

## 核心原则
- 手动自定义编辑与 AI 驱动编辑是同等重要的产品入口，能在同一效果中反复切换。
- AI 是软件的自然语言操作层，不是孤立聊天窗口。
- AI 与人工编辑共用同一份 Project Graph。
- AI 负责理解、规划、建议和调用工具；Graph Engine 负责确定性执行。
- 重要修改可预览、可确认、可撤销。
- 首版优先 2D/2.5D，底层数据模型预留 3D。
- 手动工作流不依赖 AI 服务，断网时仍可编辑和渲染。

## 用户入口
**手动创作：** 添加/删除节点、连接 Socket、编辑参数和关键帧曲线、预览、撤销、保存和导出。  
**AI 驱动创作：** 从描述创建效果，或选中现有效果/节点后用自然语言修改；系统生成结构化 Patch 和预览，展示改动摘要，用户确认应用或拒绝。AI 写入后仍是正常可编辑的节点图/参数，用户可立即手工继续调整；任何手工改动也可继续交给 AI 解释或迭代。两条路径共用 Project Graph、Revision、校验、Undo 和保存。

示例指令：
- “做一个蓝白色雷电球，三层不规则电弧，快速闪烁，持续 1.2 秒。”
- “把当前拖尾改成前端细、尾部渐隐，并增加轻微摆动。”
- “粒子数量减少 30%，尽量保持视觉密度。”
- “检查当前节点图的转角折痕并提出修复方案。”

## 标准流程
Create Project → Create Effect（Manual / AI / Template）→ Build Graph → Compile → Preview → Tune（手动或 AI）→ Save / Export。Manual 与 AI 是并列入口，可在同一工程中反复切换；模拟缓存和 Bake 在支持 Simulation 的阶段启用。

## 首个可用版本范围
以一条可交付的 2D/2.5D 游戏特效创作路径为验收目标：创建工程、手动编辑强类型节点图/参数/关键帧、CPU/经验证的预览、保存重开，并导出引擎无关 PNG 序列或 Sprite Sheet + Atlas JSON。项目、图、资源、基础撤销、错误诊断、导出往返属于 P0；引擎专属 Runtime 插件不属于首版。

AI 驱动编辑也是首个可用版本的核心路径：用户可描述生成或修改目标，AI 基于当前工程创建可编辑 Graph/Parameter Patch，显示摘要、校验和预览，经用户确认后应用；与手动操作共用项目数据、Revision、保存和 Undo。高级视觉迭代、多 Provider 自动路由、MCP、多 Agent、插件 SDK、多目标导出以及全部 Simulation/Field/Attribute/Instance 能力可按阶段扩展。详细要求见[手动与 AI 双模编辑规格](11_手动与AI双模编辑规格.md)。

首发平台/引擎无关导出/发行模式/BYOK 方向已由 ADR-0001 确认。仍待实测或选择：最低硬件、GPU 预览是否纳入 P0、具体 Provider/model、P0 效果族与代表性验收场景；见[项目执行与技术美术规范](09_项目执行与技术美术规范.md)。

暂不承诺通用电影级 3D DCC、完整 NLE、复杂流体求解器、任意用户代码执行和无需人工检查的全自动生产。
