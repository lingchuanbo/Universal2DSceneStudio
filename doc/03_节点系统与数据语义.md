# 03 VFX Graph Engine：Geometry Nodes + Houdini 融合
## 设计来源
借鉴 Blender Geometry Nodes：Geometry Set、Domain、Field、Attribute、Instance、Node Group、Simulation Zone。  
借鉴 Houdini：SOP 式程序化网络、属性流、可诊断执行链、缓存/烘焙、可组合操作。  
VFXForge 自主扩展：Effect/Particle/Trail/Sprite/Vector Field 特效类型、AI 可理解 Node Descriptor、GPU 执行和 2D/2.5D 工作流。

## 三层语义
- Data Flow：Socket 传输数据。
- Execution Flow：决定运行时机、缓存、并行和增量更新。
- Effect Flow：表达生命周期、事件、渲染顺序和组合关系。

## 节点类别
| 类别 | 典型节点 |
|---|---|
| Geometry | Create Shape、Path、Resample、Extrude、Mesh From Path |
| Attribute | Set / Get Attribute、Store Named Attribute |
| Field | Noise Field、Vector Math、Map Range、Random Field |
| Procedural | Repeat、Scatter、Distribute、Curve Deform |
| Particle | Emit、Initialize、Update、Kill、Render |
| Simulation | Simulation Input/Output、Collision、Force |
| Material | Color Ramp、Gradient、Texture、Blend |
| Composite | Alpha Over、Glow、Distortion、Mask |
| Utility | Switch、Reroute、Group Input/Output、Debug |

## Socket 类型
Bool、Int、Float、Float2/3/4、Color、String、Enum、Image、Texture、Curve、Geometry、Field、Material、ParticleSet、Event、SimulationState。禁止默认 Any；转换通过显式 Converter Node 或明确安全转换。

## Graph 编译
校验节点和 Socket → 类型检查 → 普通 DAG 环路检测 → 识别 Simulation Zone 反馈 → 拓扑排序 → 生成 Graph IR → 后端选择 → 调度执行 → 诊断与缓存键。

## Geometry / Domain / Field / Attribute
GeometrySet 包含 PointCloud、Curves、Mesh、Instances、Metadata。首批 Domain：Point、Curve、Spline、Face、Edge、Corner、Instance。Field 是延迟求值表达式，只有节点需要具体结果时才 Evaluate。Attribute 有名称、类型、Domain、读写权限和版本。

## Instance
支持 Instance on Points / Curve / Grid / Realize Instances。默认保留实例化，只有逐顶点修改或导出需要时才 Realize。

## 路径转面片
Input Curve → Resample → Tangent/Normal → Width Profile → Boundary → Join/Cap → Mesh Output。必须处理 Miter/Bevel/Round Join、Miter Limit、自交检测、曲率采样、首尾宽度、中段宽度、拖尾曲线、UV 和透明渐变。

## Simulation Zone（扩展阶段）
纳入 Simulation 阶段后，状态反馈必须显式放在 Simulation Zone：State(t) + Events(t) + Forces(t) → Update → State(t+Δt)。目标要求固定时间步、子步数、确定性随机种子、状态快照、Bake/Reset/Clear Cache 和时间跳转恢复。建议首批实现粒子生命周期、速度积分、简单力场、边界碰撞和拖尾历史点；以上是扩展能力，不构成垂直切片的先决条件。
