# 02 总体架构与 Project Graph
## 分层架构
```text
VFXForge Studio
├─ UI/UX: Viewport / Node Editor / Timeline / Inspector / AI Workspace
├─ Interaction: Commands / Selection / Undo-Redo / Tool API / Event Bus
├─ Project Core: Project Graph / Assets / Parameters / Animation / History
├─ VFX Graph Engine: Registry / Compiler / Graph IR / Scheduler / Runtime
├─ AI Agent Host: Context Builder / Planner / Skills / Tool Permission
├─ Domain Engines: Geometry / Field / Attribute / Particle / Simulation / Material / Composite
├─ Compute & Render: CPU Reference / GPU Runtime / wgpu / WGSL
└─ Platform: Storage / Cache / Media Worker / Plugin Host / IPC / Logging
```

## 三种图
- **Project Graph：** 工程实体、资产、效果、参数、动画、依赖和引用关系，是项目权威数据源。
- **Processing Graph：** 描述效果如何由节点计算。普通图是 DAG；有状态反馈必须放在显式 Simulation Zone。
- **AI Task Graph：** 描述 AI 为完成用户目标拆分的步骤、依赖和工具调用，不是渲染图。

手动 Editor Commands 与 AI Tool API/Patches 都经过同一 Project Core Command/Transaction 边界操作 Project Graph。AI Task Graph 仅描述 AI 为完成用户目标拆解的步骤，不是渲染图或第二份工程数据。Project Graph 保存 Processing Graph；Graph Compiler 将 Processing Graph 编译为 IR 和执行计划。

```text
Manual UI Command ─┐
                   ├─> Validate -> Atomic Transaction -> Project Graph/Revision -> Undo/Save
AI Graph Patch ────┘            └─> Compile/Preview (AI 草稿隔离，不提前提交)
```

手动改动和已 Apply 的 AI 改动都修改同一权威模型并产生同一类历史记录；AI Task Record 只附加来源/提示/Patch/结果元数据，不替代工程历史。AI 写入前必须检测 Revision 和读/写集合冲突。详细交互、失败语义和验收见[文档 11](11_手动与AI双模编辑规格.md)。

## Project Graph
```text
Project
├─ ProjectInfo
├─ AssetDatabase
├─ CompositionDatabase
├─ EffectEntities
├─ ProcessingGraphs
├─ AnimationData
├─ SimulationCaches
├─ PluginRecords
├─ AIRecords
├─ History / Transactions
└─ Settings
```
采用 Entity + Component 组合。Entity 包括 Effect、Shape、Path、Particle System、Emitter、Force Field、Sprite、Text、Camera、Controller。Component 包括 Transform、Geometry、Material、Animation、Visibility、Simulation、RenderSettings、Metadata。

每个 Entity/Node/Socket/Asset 使用稳定 UUID。Project Revision 在每次成功 Transaction 后递增。AI 修改必须携带 expected_revision；发生冲突时重新读取相关上下文，不得覆盖新修改。

参数必须定义类型、默认值、范围、单位、是否可动画、是否允许 AI 修改及描述。支持普通值、动画值和 Field 值。

## 项目文件
建议 `.vfxproj` 容器包括 `project.json`、`graphs/`、`assets/`、`cache/`、`ai/`、`previews/` 和 `manifest.json`。采用 Journal + Snapshot + Autosave。缓存可清理，源数据不可依赖缓存恢复。
