# 12 实现级技术设计（P0）

> 状态：Implementation Baseline v0.1；方向依据 [ADR-0001](decisions/ADR-0001-product-baseline.md)。本文是编码基线，不表示软件已经实现。

## 1. 交付切片

P0 要求 Windows 10/11 x64 用户可创建/保存/重开项目，手动编辑强类型节点图和曲线，预览/撤销；可配置 BYOK 云端 AI，描述创建效果或修改当前效果，先看摘要/预览并明确确认；可导出 PNG 序列或 Sprite Sheet + Atlas JSON。AI Patch Apply 后仍可手工继续编辑同一 Project/Graph。AI 离线不影响手动功能。

P0 不包含引擎专属插件、实时引擎粒子 Runtime、Simulation Bake、MCP、多 Agent、任意代码节点或 AI 自动应用。

## 2. Rust 模块边界

```text
apps/vfxforge-studio       启动、窗口/菜单/文件对话框组装
crates/vfx_types           stable ID、Revision、单位、共享错误/值类型
crates/vfx_project         Project 模型、包读写、migration、资源索引
crates/vfx_graph           Node Descriptor、图结构、socket 校验、诊断
crates/vfx_commands        Manual 可见的序列化编辑命令
crates/vfx_transaction    Prepare/Preview/Commit、revision、history、Undo
crates/vfx_runtime_cpu     P0 确定性参考运行时
crates/vfx_render          视口绘制、目标图像/帧生成，设备所有权隔离
crates/vfx_preview         candidate、patch diff、诊断、预览生命周期
crates/vfx_export          PNG、图集 packing、manifest/hash
crates/vfx_ai_provider     BYOK provider trait、网络/取消/超时
crates/vfx_ai_agent        上下文裁剪、计划、受限 Patch 解析
crates/vfx_ui_adapter      BUI 输入 -> Commands；Core Read Models -> BUI
```

依赖规则：UI 不拥有数据；AI/Manual 共用 Transaction Service；Project/Graph/Runtime/Export 不依赖 BUI、HTTP 或模型供应商；核心数据不含 BUI 类型。AI 网络调用后台运行，UI/Core 主线程只交换不可变 snapshot、command 和结果事件。仅在 [ADR-0002](decisions/ADR-0002-ui-bui.md) 原型门禁过后固定 UI binding。

## 3. 项目包格式

`.vfxproj` 为 ZIP64 容器，最小目录：

```text
manifest.json
 graphs/<graph-id>.json
 assets/<asset-id>/<safe-name>
 ai/tasks/<task-id>.json
 cache/                         # 可清理的派生数据
```

真实 entry path 为 `graphs/...`（树中缩进仅供可读性）。契约草案见 [`project-manifest.schema.json`](schemas/project-manifest.schema.json)。

- Project Revision 单调递增；Project/Effect/Graph/Node/Socket/Asset 稳定 ID。
- 路径拒绝绝对路径、`..`、符号链接逃逸、规范化碰撞；限制解压总字节、文件数量和压缩比。
- 写入同目录 staging 文件，flush 后重开校验 ZIP/Schema/资源哈希，通过后原子替换；失败保留旧文件。启动时检测 autosave 并询问恢复。
- UTF-8 JSON，拒绝重复键和 NaN/Infinity；稳定排序后序列化。资源 SHA-256 对原始字节计算。
- `format_version` 与 App version 分开；每个 migration 有备份、来源/目标版本、错误定位和测试。遇到 reader 不支持的新版本时只读提示或拒绝，不静默删字段。
- 缓存不属于恢复源数据；Key、HTTP body/header、机器绝对路径不写工程。AI Task 默认仅存摘要、context/patch digest 与结果状态。
- 仍需实现验证 manifest 中 effect/graph 关联、所有引用 ID 唯一、路径存在及 hash 匹配。

## 4. 命令与事务契约

编辑命令最小集：`CreateEffect`、`AddNode`、`RemoveNode`、`MoveNode`、`Connect`、`Disconnect`、`SetParameter`、`SetKeyframe`、`RemoveKeyframe`、`ImportAsset`。AI Patch 仅使用白名单结构化操作，禁止任意对象反序列化覆盖。

```text
prepare(project_id, expected_revision, commands) -> PreparedTxn
preview(prepared_id) -> PreviewResult
commit(prepared_id, user_approval_token) -> {new_revision, transaction_id, undo_id}
undo/redo(undo_id, expected_revision) -> CommitResult
```

`prepare` 在不可变 snapshot 上验证 schema、node/socket/version、参数范围、对象权限、预算。Host 根据上下文/命令推导 canonical read/write set，与 Patch 声明比对；不得信任模型自报对象集合。`preview` 在隔离 candidate 上执行完整命令、编译/渲染、生成 diff/diagnostic，不改变 revision、dirty、history 或源文件；Preview 绑定 revision+patch digest+TTL。`commit` 再检查 revision、preview 未过期、审批 token 对应 patch digest，完整成功后一次性提交整个事务、revision+1、dirty、history、undo record。任何错误全回滚。P0 revision 冲突返回错误，不自动 rebase。Undo 自身是新事务，不允许用整工程旧快照覆盖后续手工编辑。

所有 P0 AI 写入要求 `requires_approval: true`。首版没有自动化写模式。详见 [`graph-patch.schema.json`](schemas/graph-patch.schema.json)；Schema 不替代语义校验。

## 5. BYOK 安全边界

Provider 接口只返回结构化 Plan/Patch，不生成或执行代码。首个 Adapter 以 OpenAI-compatible Chat Completions + JSON mode/schema 子集做原型；具体服务商/model 仍待确认，兼容性必须实测。

- Key 放 Windows Credential Manager/等效 OS Secret Store；设置和工程只存 opaque credential reference。Key 不进日志、崩溃报告、Activity、Patch、导出；删除设置提供清除 Secret 功能。
- TLS、连接/总超时、取消、响应字节上限、429/5xx、预算和 JSON Schema 校验均需测试；日志不含 raw request/response。
- 发送前 UI 显示 Provider/model 和数据类别（摘要、选中图、节点描述、诊断、预览图等），用户授权；默认不发未选资产。
- 未配置/未授权/离线时 Manual 流程完整可用。Activity 只存意图摘要、context digest、共享数据类别、provider/model、patch digest、状态、revision 和 transaction ID；schema 见 [`ai-task-record.schema.json`](schemas/ai-task-record.schema.json)。

## 6. P0 Runtime/Node 子集

建议 P0 首批固定为：`ImageSource`、`Constant`、`Time`、`SeededRandom`、`Math`、`ColorRamp`、`ParticleEmitter`、`ParticleInitialize`、`ParticleUpdate`、`TrailBuild`、`ColorOverLife`、`SizeOverLife`、`SpriteRender`、`EffectOutput`。不先实现完整 Geometry Nodes/Houdini。

Descriptor 必须记录 type id/版本、分类/说明、输入输出 Socket、参数 schema/default/range/unit、可动画、CPU capability、确定性、成本提示、诊断文本和最小示例。缺节点/版本以 opaque data 保留，标不可运行诊断；禁止加载时删除并覆盖。

关键帧时间单位为秒，finite 且非负；同一参数同一时间只允许一个 key；插值 constant/linear/bezier。随机数由 project seed/effect/emitter/particle stable ID/spawn ordinal 确定，不依赖线程遍历顺序。角度用弧度；图像颜色空间和 Straight/Premultiplied Alpha 明确记录。

## 7. PNG/Atlas 输出

导出配置契约见 [`export-profile.schema.json`](schemas/export-profile.schema.json)，图集数据契约见 [`atlas-manifest.schema.json`](schemas/atlas-manifest.schema.json)。帧区间用 `[start_inclusive, end_exclusive)`；FPS 使用整数 numerator/denominator，避免浮点时间漂移。输出先写 staging 目录，成功后原子替换；同名默认失败，替换需确认或用 versioned 目录。

Atlas JSON 由 `atlas-manifest.schema.json` 定义。跨字段语义校验至少检查帧数等于 end_exclusive-start_inclusive、frame index 连续、time = index_delta * fps.denominator/fps.numerator、所有 rect 不越出纹理边界且互不重叠（packing padding/extrude 规则除外）、packing.rotated=false 和 path/hash 匹配。字段包含版本、effect ID、FPS、帧区间、canvas、pivot/bounds、color/alpha、纹理 path/hash、packing padding/extrude 和每帧 index/time/rect/trim offset/original size。Rect 原点左上，整数像素、半开区间 `[x,y,w,h]`，默认不旋转。P0 交付的是逐帧图像，不是可在引擎中参数化驱动的粒子 Runtime。

## 8. 发布/测试门禁

项目测试覆盖 atomic write/recovery/migration/path traversal/Zip bomb/hash mismatch；Command conformance suite 同时用于 Manual 与 AI；Graph 覆盖 missing node/socket/cycle/serialization；固定 Seed 多次结果像素稳定；BYOK mock 测 Key 不落盘、超时/取消/429/坏 JSON/无网/未授权数据；导出测帧数/FPS/alpha/color-space/图集越界/hash。许可证发布须包含 SPDX、SBOM、Notices 和审查确认。
